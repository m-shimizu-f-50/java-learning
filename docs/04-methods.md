# 04. メソッド

## 用語集

- **オーバーロード**: 同じ名前で、引数の型・数が異なる複数のメソッドを1つのクラスに定義すること
- **エントリーポイント**: プログラムの実行が最初に始まる場所。Javaでは`main`メソッドがこれにあたる
- **JVM（Java Virtual Machine）**: コンパイルされたJavaのコード（バイトコード）を実行する仮想マシン。OSの違いを吸収し、どの環境でも同じJavaコードを動かせるようにする
- **シグネチャ**: メソッド名と引数の型・数の組み合わせのこと。オーバーロードはこのシグネチャの違いで区別される

## 使い方

### 基本構文

```java
戻り値の型 メソッド名(引数の型 引数名, ...) {
    ...
    return 戻り値;
}
```

戻り値がない場合は `void` を使う。

### オーバーロード

Javaは同名・引数違いのメソッドを複数定義できる（JSにはない概念）。

### static

`main`から直接呼ぶメソッドは今の段階では `static` をつける（詳細はオブジェクト指向で扱う）。

### エントリーポイント

```java
public static void main(String[] args) {
    ...
}
```

これはJVMがプログラムのエントリーポイントとして認識するための決まったシグネチャ。定型文として覚えてよい。

## 覚えておくべきルール・規約

- 戻り値がない場合は`void`を指定する
- 同名でも引数が違えば複数定義できる（オーバーロード）
- `main`から直接呼ぶメソッドには`static`をつける
- `public static void main(String[] args)`はJVMが認識する決まったシグネチャで変更不可
