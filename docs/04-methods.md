# 04. メソッド

## 要点

- 構文: `戻り値の型 メソッド名(引数の型 引数名, ...) { ... return 戻り値; }`
- 戻り値がない場合は`void`
- Javaはオーバーロード（同名・引数違いのメソッドを複数定義）が可能（JSにはない概念）
- `main`から直接呼ぶメソッドは今の段階では`static`をつける（詳細はオブジェクト指向で扱う）
- `public static void main(String[] args)` はJVMがプログラムのエントリーポイントとして認識するための決まったシグネチャ（定型文として覚えてOK）

## 演習

`04-methods/Main.java` にて以下を実装。

1. `max(int a, int b)`: 大きい方の値を返す
2. `sum(int[] nums)`: 配列の合計を返す
3. `greet(String name)`: `"Hello, " + 名前 + "!"` を返す
4. `main`から呼び出して結果を出力
