# 03. 配列

## 要点

- 配列は固定長（JSのようにpush等でサイズを変えられない）
- 同じ型の要素しか入れられない
- `array.length`はプロパティ（メソッドではないので`()`不要）
- 拡張for文（`for (int n : nums)`）で全要素を簡潔に走査できる
- 多次元配列は `int[][] matrix = {{1,2},{3,4}};` のように定義
- 可変長が必要な場合は`ArrayList`（Java応用トピックで扱う）

## 演習

1. `int[] scores = {80, 65, 90, 72, 55};`
2. 拡張for文で全要素出力
3. 通常のfor文で合計計算
4. 平均点（double）を計算
5. 2次元配列 `table[1][0]` の値を出力

## つまずいた点・フィードバック

- 特につまずきなし。整数除算を避けるための`(double)`キャストも正しく使えていた。
- 演習コードは `03-array/Main.java`。コンパイル・実行して動作確認済み（合計362、平均72.4、table[1][0]=3）。
