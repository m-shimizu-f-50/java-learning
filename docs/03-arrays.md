# 03. 配列

## 使い方

### 配列の宣言

```java
int[] scores = {80, 65, 90, 72, 55};
```

配列は固定長で、JSの `push` のようにサイズを後から変えることはできない。また同じ型の要素しか入れられない。

### 走査

```java
for (int n : scores) {
    // 拡張for文で全要素を走査
}
```

`scores.length` は配列の長さを持つプロパティ（メソッドではないので `()` 不要）。

### 多次元配列

```java
int[][] table = {{1, 2}, {3, 4}};
table[1][0]; // 3
```

### 可変長が必要な場合

サイズが変わる配列が必要な場合は `ArrayList` を使う（Java応用トピックで扱う）。

## 覚えておくべきルール・規約

- 配列は固定長。生成後にサイズを変更できない
- 配列には同じ型の要素しか入れられない
- `array.length`はプロパティ（`()`をつけない）
- 可変長が必要なら`ArrayList`を使う

## 演習

1. `int[] scores = {80, 65, 90, 72, 55};`
2. 拡張for文で全要素出力
3. 通常のfor文で合計計算
4. 平均点（double）を計算
5. 2次元配列 `table[1][0]` の値を出力

演習コードは `03-array/Main.java`。コンパイル・実行して動作確認済み（合計362、平均72.4、table[1][0]=3）。
