# 01. 変数と型

## 使い方

### 変数宣言

```java
型 変数名 = 値;
```

Javaは静的型付け言語。変数宣言時に型を明示する必要があり、JSの `let x = 1` のように後から別の型を代入することはできない。

### 型の種類

| 分類 | 型 | 説明 |
|---|---|---|
| プリミティブ型 | `int`, `double`, `boolean`, `char`, `long`, `float`, `byte`, `short` | 値そのものを保持する |
| 参照型 | `String`, 配列, クラスなど | オブジェクトへの参照を保持する |

### 定数

```java
final double TAX_RATE = 0.1;
```

`final` をつけると再代入不可になる。JSの `const` に相当。

### 実例

```java
int age = 25;
double price = 19.99;
boolean isActive = true;
char grade = 'A';
String name = "Alice";
final double TAX_RATE = 0.1;
```

## 覚えておくべきルール・規約

- 実行可能なコードは必ずクラス＋`main`メソッドの中に書く（トップレベルに文を書けない）
- 1ファイルにつき`public`クラスは1つまで。ファイル名とpublicクラス名を完全一致させる（拡張子`.java`を除く、数字始まり・ハイフンは不可）
- `double`型の小数計算には誤差が出る。金額など正確性が必要な場面では`BigDecimal`を使う

## 演習

1. 整数型の変数 `quantity` に `3` を代入
2. 小数型の変数 `unitPrice` に `250.5` を代入
3. `quantity * unitPrice` の合計金額を計算し `double` 型の変数 `total` に格納
4. `final` を使って税率 `0.1` を定数として宣言
5. 合計金額に税率を加えた金額を標準出力に表示

演習コードは `01-variables-types/Main.java` に配置。コンパイル・実行して動作確認済み。

## つまずきの分析

### 実行コードはどこに書くか

**何が起きたか**: すべての実行コードをクラス＋`main`メソッドの中に書く必要がある点で戸惑った。

**なぜ**: JSはトップレベルに文を直接書けるスクリプト言語だが、Javaはすべてのコードが何らかのクラスに属していなければならない、という設計思想の違いによる。

**教訓**: Javaの記法で「なぜこんなに書くことが多いんだろう」と感じたら、「JSがゆるく許していたことをJavaは厳密に要求している」パターンを疑うとよい。

### クラス名とファイル名

**何が起きたか**: `public class` の名前とファイル名を一致させる必要があることを知らずにつまずきかけた。

**なぜ**: Javaはコンパイラがソースファイル名からpublicクラスを特定する仕様になっている。

**教訓**: ファイル名を決める前に、そこに置く `public class` 名を先に決める。

### doubleの小数誤差

**何が起きたか**: `826.65` を計算したはずが `826.6500000000001` という結果になった。

**なぜ**: `double` は2進数表現のため、`0.1` のような10進小数を正確に表現できない。JSの `Number` 型（IEEE754倍精度浮動小数点）も同じ制約を持つが、JS開発では金額計算をそこまで厳密に扱う場面が少なく意識していなかった。

**教訓**: 実務で金額など正確性が求められる値を扱う場合は `BigDecimal` を使う（応用トピックで扱う予定）。
