# 06. 継承

## 要点

- `extends`: 親クラス（スーパークラス）を継承する
- `super(...)`: 親クラスのコンストラクタを呼び出す。子クラスのコンストラクタの1行目に書く必要がある
- 子クラスは親クラスの`public`/`protected`なフィールド・メソッドをそのまま使える
- **オーバーライド**: 親と同じシグネチャのメソッドを子クラスで再定義できる。`@Override`アノテーションを付けるのが慣習
- Javaは単一継承のみ（1クラスしか継承できない）。複数の型の性質を持たせたい場合はインターフェースを使う（次のトピック）

## `@Override`はいつ書くか

「2つ以上のクラスが継承している場合」ではなく、**「親クラスに既にあるメソッドを、そのクラス単体で上書きするとき」**に書く。

- 親のメソッドをそのまま使う（継承のみ）→ `@Override`不要
- 親のメソッドを独自に再定義する（オーバーライド）→ `@Override`が必要

`@Override`は言語仕様上は任意だが、メソッド名のタイポなどで「オーバーライドのつもりが実は新しいメソッドになっていた」という凡ミスをコンパイルエラーとして検出できるため、オーバーライドする際は毎回付けるのが慣習。

## 演習

`06-inheritance/`にて以下を実装。

1. `Animal`クラス: `name`フィールド、コンストラクタ、`eat()`メソッド
2. `Dog`クラス（`Animal`継承）: 独自メソッド`bark()`
3. `Cat`クラス（`Animal`継承）: `eat()`を`@Override`
4. `Main`で`Dog`・`Cat`のインスタンスを生成し、`eat()`と固有メソッドを呼び出し

- `@Override`の意味（「2箇所以上での継承」ではなく「そのクラス単体でのオーバーライド」を示すもの）を確認
